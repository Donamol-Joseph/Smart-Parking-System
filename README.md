# Smart Parking System

A modern GUI-based Smart Parking Management System developed using Java Swing and Object-Oriented Programming concepts.

---

## Overview

This project simulates a real-world smart parking system with dynamic parking slot allocation, waiting queue management, and interactive GUI controls.

The system automatically parks vehicles, manages occupied slots, and handles overflow using a queue-based waiting list mechanism.

---

## Features

- Interactive Java Swing GUI
- Dynamic Parking Slot Grid
- Car & Motorcycle Support
- Waiting Queue Management
- Automatic Slot Updates
- Vehicle Removal System
- Exception Handling
- Object-Oriented Design
- Queue Data Structure Implementation

---

## System Functionalities

### Vehicle Parking

- Parks vehicles in available slots
- Updates GUI dynamically

### Waiting Queue

- Adds vehicles to queue when parking is full
- Automatically parks queued vehicles when slots become available

### Vehicle Removal

- Removes parked vehicles
- Refreshes parking slot status instantly
